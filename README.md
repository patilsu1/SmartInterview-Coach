# Smart Interview Coach – AI-Powered Chatbot for Resume + JD Analysis

## Overview

Smart Interview Coach is an AI-powered chatbot that helps job seekers enhance their resumes and prepare for interviews by analyzing their current resume against a specific job description. It identifies skill gaps, suggests tailored resume edits, and generates custom interview questions with STAR-format sample answers.

## Features

- Resume vs. Job Description Analysis
- Tailored Resume Suggestions
- Interview Question Generator
- STAR-Formatted Sample Answers

## Tech Stack

- Language: Python
- AI Models: OpenAI GPT-4.1 (Github->Marketplace->Models->Azure OpenAI Service->OpenAI GPT-4.1)
- Tools: Chainlit, GitHub Copilot, spaCy/nltk (optional for text processing)

## Getting Started

### Prerequisites

- Python 3.8+
- OpenAI API Key(Github Personal access token)
- Chainlit

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the App

```bash
chainlit run app.py
```
